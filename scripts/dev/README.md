# Development Utilities

Development and debugging scripts for the intent classifier project.

## Scripts

### Validation & Testing
- `test_single_label.py` - Test single-label classification with CLINC150
- `test_multi_label.py` - Test multi-label classification with NLU++
- `test_nlu_plus_dataset.py` - Test NLU++ dataset loader
- `test_llm_connection.py` - Test Ollama and OpenAI connections

### Development Tools
- `check_commit_message.py` - Validate commit messages
- `check_config_loaders.py` - Validate configuration loaders
- `check_env_file.py` - Check environment file setup
- `check_full_dataset.py` - Validate full dataset
- `debug_predictions.py` - Debug prediction issues
- `explain_train_test_split.py` - Explain train/test split logic

These scripts are primarily for development and debugging purposes.
