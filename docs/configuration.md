## Configuration

## Overview

Configuration for this project is defined through layered YAML files plus a small
set of environment variables.

- See `config.md` for the current layering rules, `resolved.*` fields, and
  environment‑based selection via `DATASET` / `VARIANT`.
- See `output_schema.md` for how `run_id` maps to
  `output/runs/<label_type>/<dataset>/<variant>/`.
