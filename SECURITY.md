# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, please report it responsibly:

1. **Email**: Contact the maintainers directly (see repository maintainers)
2. **Description**: Provide a clear description of the vulnerability
3. **Steps to reproduce**: If applicable, include steps to reproduce
4. **Impact**: Describe the potential impact

We will:
- Acknowledge receipt within 48 hours
- Provide an initial assessment within 7 days
- Keep you informed of the progress
- Credit you in the security advisory (if desired)

## Security Best Practices

When using this project:

- **API Keys**: Never commit API keys or secrets to version control
- **Environment Variables**: Use `.env` files (not committed) for sensitive configuration
- **Dependencies**: Keep dependencies up to date
- **Input Validation**: Always validate user input when using the API

Thank you for helping keep this project secure!
