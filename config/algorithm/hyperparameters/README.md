# Hyperparameters

## Overview

Tuned hyperparameters for all models, generated by the hyperparameter tuning pipeline.

## Files

- `best_{model_name}.yaml` - Individual files for each model
- Example: `best_naive_bayes.yaml`, `best_transformer_logreg.yaml`

## Usage

Hyperparameters are automatically loaded by the training pipeline. If a tuned file
is not found, models use defaults from `config/algorithm/models_config.yaml`.

## Generating Hyperparameters

Use the `intent-tune` CLI (see `docs/hyperparameter_tuning.md` for details):

```bash
uv sync --extra tune

uv run --active intent-tune --config config/experiments/clinc150/tiny.yaml
```

This saves results to:
- `config/algorithm/hyperparameters/{config_name}/` (used by the training pipeline)
- `output/hyperparams_tune/{config_name}/` (reference from Ray Tune)

## Git

These files should be committed to the repository as they are:
- Small configuration files
- Reproducible
- Useful for collaboration
- Documentation of hyperparameters used
